# Zapier MCP quickstart

The Zapier MCP server serves this skill, so it stays current. Load it with `get_zapier_skill` (skill `zapier:quickstart`) and follow it. If you already loaded `zapier:quickstart` in this chat, follow that copy.

If no Zapier tools are available, or `get_zapier_skill` fails with an authentication error, use the **zapier-connect** skill first. It hands back to this skill when Zapier is connected.
